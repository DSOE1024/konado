# 信号

## 功能描述

在对话场景中的自定义信号，可以用于几乎任何操作

## 语法结构

```text
signal <自定义信号指令>
```

## 参数详解
| 参数 | 必需 | 示例 | 说明 |
|------|------|------|------|
| 自定义信号指令 | 是 | 好感度上升 | 具体指令 |


## 示例
```text
# 示例
signal 好感度上升
signal 好感度下降
signal 金币设置好感度 50
```

## 回退行为

`signal` 是**可重放**的一次性副作用：对话回退（上一句）可以跨越它，继续播放再次经过该指令时会**重新发射**，因此重选分支会再次触发处理函数。

- 处理函数只改**快照内**状态（脚本变量、镜头、角色、背景、音频、界面）时，回退 + 重放的结果与全新播一次完全一致（demo 里 `signal 好感度上升` → `%love + 1` 就属于这种情况）；
- 处理函数改**快照之外**的状态（单例、外部存档、自定义 Resource）时，需要自行保证幂等；
- 成就指令（`achievement unlock` / `increment` / `set_flag`）属于外部累计状态：跨越后**不会重放**，成就不会被记两次。

详见 [对话回退（上一句）](../core/dialogue-rollback.md) 的「变量与副作用」一节。
