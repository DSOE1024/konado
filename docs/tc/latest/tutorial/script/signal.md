# 訊號

## 功能描述

對話場景中的自訂訊號，可用於幾乎任何操作。

## 語法結構

```text
signal <自訂訊號指令>
```

## 參數詳解
| 參數 | 必需 | 範例 | 說明 |
|------|------|------|------|
| 自訂訊號指令 | 是 | 好感度上升 | 具體指令 |

## 範例
```text
# 範例
signal 好感度上升
signal 好感度下降
signal 金幣設定好感度 50
```

## 回退行為

`signal` 是**可重放**的一次性副作用：對話回退（上一句）可以跨越它，繼續播放再次經過該指令時會**重新發射**，因此重選分支會再次觸發處理函式。

- 處理函式只改**快照內**狀態（腳本變數、鏡頭、角色、背景、音訊、介面）時，回退 + 重放的結果與全新播一次完全一致（demo 裡 `signal 好感度上升` → `%love + 1` 就屬於這種情況）；
- 處理函式改**快照之外**的狀態（單例、外部存檔、自訂 Resource）時，需要自行保證幂等；
- 成就指令（`achievement unlock` / `increment` / `set_flag`）屬於外部累計狀態：跨越後**不會重放**，成就不會被記兩次。

詳見 [對話回退（上一句）](../core/dialogue-rollback.md) 的「變數與副作用」一節。
