# 演員切換狀態

## 功能描述
切換指定演員的狀態。預設會依序淡出目前狀態、套用新狀態、淡入新狀態，並在轉場完成後繼續執行劇情。

## 語法結構

```text
actor change <角色名稱> <新狀態>
```

## 參數詳解

| 參數 | 必需 | 範例 | 說明 |
|------|------|------|------|
| 角色 | 是 | kona | 指定要切換狀態的演員名稱 |
| 新狀態 | 是 | happy | 指定要切換到的新狀態 |

## 範例

```text
actor change kona happy
```

## 狀態切換轉場

`actor change` 的預設轉場順序如下：

1. 目前角色淡出。
2. 角色場景套用新狀態。
3. 角色以新狀態淡入。
4. 轉場結束後，繼續執行下一條劇情指令。

可以在 `KND_ActingInterface` 節點的屬性面板中設定轉場：

| 屬性 | 預設值 | 說明 |
|------|--------|------|
| `enable_actor_state_fade` | `true` | 是否為演員狀態切換啟用淡入淡出 |
| `actor_state_fade_duration` | `0.3` | 完整轉場的總時長（秒）；淡出和淡入各占一半 |

關閉 `enable_actor_state_fade` 或將 `actor_state_fade_duration` 設為 `0` 時，狀態會立即切換。

轉場作用於穩定的角色掛載層，不會複製角色場景，因此圖片、影片、Spine、Live2D 和自訂角色場景可以使用相同的切換流程。找不到目標演員或角色場景無法套用該狀態時，系統會結束本次指令並繼續劇情，不會持續等待。
