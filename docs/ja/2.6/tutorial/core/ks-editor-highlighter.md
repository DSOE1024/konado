# Godot 内蔵 KonadoScript エディター

Konado プラグインを有効にした後、ファイルシステムドックで `.ks` ファイルをダブルクリックすると、下部の `KonadoEdit` パネルで開きます。エディターは元の KonadoScript ファイルを直接編集し、保存後に Godot の再インポートを実行します。

## 編集機能

- 複数の `.ks` ファイルをタブで編集し、ファイルごとのカーソル位置と未保存状態を保持
- 復元用の下書きを自動保存し、エディターやプラグインが中断した後に復元可能
- 外部変更を検出し、未編集のファイルは自動再読み込み、競合時は確認ダイアログを表示
- 検索、置換、指定行への移動、ローカル分岐シンボルへの移動
- ステートメント一覧から現在対応しているすべての KonadoScript コマンドを挿入

## ハイライトと補完

`KND_KsHighlighter` は Godot の `SyntaxHighlighter` を基に実装されています。ハイライト、コード補完、ステートメントテンプレートは `KS_LanguageCatalog` を共有し、有効なキーワードはパーサーの `KS_Token.KEYWORDS` を基準とします。コマンドを追加または削除した際は、自動テストが両者の整合性を確認します。

ハイライト用の正規表現は初回だけコンパイルされ、各行には色が変化する位置だけが記録されます。編集やスクロールのたびに正規表現を再コンパイルしたり、文字ごとの辞書項目を生成したりしません。

デフォルトのハイライトリソース：

```text
res://addons/konado/editor/ks_editor/highlighter.tres
```

独自エディターから直接生成することもできます。

```gdscript
set_syntax_highlighter(KND_KsHighlighter.new())
```

## リアルタイム診断

入力を短時間停止すると、ランタイム用の `KND_Shot` リソースを生成せずに、字句・構文・意味解析を実行します。エラーと警告は次の場所に表示されます。

- コード行のガターマーカーと背景色
- エディター下部の問題一覧

問題またはガターマーカーをクリックすると、該当位置へ移動できます。保存時には通常の Godot インポートも実行されるため、リアルタイム診断は正式なインポート結果を置き換えるものではありません。

## ショートカット

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 保存 | `Ctrl+S` | `Command+S` |
| 現在のタブを閉じる | `Ctrl+W` | `Command+W` |
| 検索 | `Ctrl+F` | `Command+F` |
| 検索と置換 | `Ctrl+H` | `Command+Option+F` |
| 指定行へ移動 | `Ctrl+L` | `Command+L` |
