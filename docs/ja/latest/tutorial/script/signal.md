# シグナル

## 機能説明

会話シーン内のカスタムシグナルです。ほぼ任意の操作に使用できます。

## 構文

```text
signal <カスタムシグナル命令>
```

## パラメーター
| パラメーター | 必須 | 例 | 説明 |
|------|------|------|------|
| カスタムシグナル命令 | はい | 好感度上昇 | 具体的な命令 |

## 例
```text
# 例
signal 好感度上昇
signal 好感度下降
signal 金貨で好感度設定 50
```

## ロールバック時の挙動

`signal` は**再生可能**な一度きりの副作用です。会話ロールバックは跨ぐことができ、再生がその命令を再び通過すると**再発火**するため、選び直した分岐ではハンドラが再び実行されます。

- ハンドラが**スナップショット内**の状態（スクリプト変数、カメラ、アクター、背景、オーディオ、UI）だけを書き換える場合、ロールバック + 再生は新規プレイとまったく同じ結果になります（デモの `signal 好感度上昇` → `%love + 1` がこの例です）；
- ハンドラが**スナップショット外**の状態（シングルトン、外部セーブ、独自 Resource）を書き換える場合は、冪等にしてください；
- 実績命令（`achievement unlock` / `increment` / `set_flag`）は外部カウンタです：**再生されない**ため、実績が二重に記録されることはありません。

詳しくは[会話ロールバック（一つ前へ）](../core/dialogue-rollback.md)の「変数と副作用」を参照してください。
