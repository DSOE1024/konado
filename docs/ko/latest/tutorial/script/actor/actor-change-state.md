# 액터 상태 전환

## 기능 설명
지정한 액터의 상태를 전환합니다. 기본적으로 현재 상태를 페이드아웃하고 새 상태를 적용한 뒤 페이드인하며, 전환이 끝나면 스토리 실행을 계속합니다.

## 문법 구조

```text
actor change <캐릭터 이름> <새 상태>
```

## 매개변수 설명

| 매개변수 | 필수 | 예시 | 설명 |
|------|------|------|------|
| 캐릭터 | 예 | kona | 상태를 전환할 액터 이름 |
| 새 상태 | 예 | happy | 전환할 새 상태 |

## 예시

```text
actor change kona happy
```

## 상태 전환 효과

`actor change`의 기본 처리 순서는 다음과 같습니다.

1. 현재 액터를 페이드아웃합니다.
2. 캐릭터 씬에 새 상태를 적용합니다.
3. 새 상태의 액터를 페이드인합니다.
4. 전환이 끝난 뒤 다음 스토리 명령을 실행합니다.

`KND_ActingInterface` 노드의 인스펙터에서 전환을 설정할 수 있습니다.

| 속성 | 기본값 | 설명 |
|------|--------|------|
| `enable_actor_state_fade` | `true` | 액터 상태 전환의 페이드 효과를 활성화합니다 |
| `actor_state_fade_duration` | `0.3` | 전체 전환 시간(초)이며, 페이드아웃과 페이드인에 절반씩 사용됩니다 |

`enable_actor_state_fade`를 끄거나 `actor_state_fade_duration`을 `0`으로 설정하면 상태가 즉시 전환됩니다.

전환은 안정적인 캐릭터 마운트에 적용되며 캐릭터 씬을 복제하지 않습니다. 따라서 이미지, 비디오, Spine, Live2D 및 사용자 캐릭터 씬에서 같은 전환 흐름을 사용할 수 있습니다. 대상 액터가 없거나 씬에서 상태를 적용할 수 없는 경우에도 명령을 완료하고 스토리를 계속하므로 무한정 기다리지 않습니다.
