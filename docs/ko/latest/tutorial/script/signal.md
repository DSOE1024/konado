# 시그널

## 기능 설명

대화 장면 안의 사용자 지정 시그널이며, 거의 모든 작업에 사용할 수 있습니다.

## 문법 구조

```text
signal <사용자 지정 시그널 명령>
```

## 매개변수 설명
| 매개변수 | 필수 | 예시 | 설명 |
|------|------|------|------|
| 사용자 지정 시그널 명령 | 예 | 호감도 상승 | 구체적인 명령 |

## 예시
```text
# 예시
signal 호감도 상승
signal 호감도 하락
signal 골드로 호감도 설정 50
```

## 되돌리기 동작

`signal`은 **재생 가능한** 일회성 부작용입니다. 대화 되돌리기는 이를 넘어갈 수 있고, 재생이 그 명령을 다시 지날 때 **재발생**하므로 다시 고른 분기에서는 핸들러가 다시 실행됩니다.

- 핸들러가 **스냅샷 안**의 상태(스크립트 변수, 카메라, 액터, 배경, 오디오, UI)만 수정한다면 되돌리기 + 재생 결과는 새로 플레이한 것과 완전히 같습니다(데모의 `signal 호감도 상승` → `%love + 1`이 이 경우입니다);
- 핸들러가 **스냅샷 밖**의 상태(싱글턴, 외부 세이브, 사용자 Resource)를 수정한다면 멱등하게 만드세요;
- 업적 명령(`achievement unlock` / `increment` / `set_flag`)은 외부 카운터입니다: **재생되지 않으므로** 업적이 두 번 기록되지 않습니다.

자세한 내용은 [대화 되돌리기(이전 대사)](../core/dialogue-rollback.md)의 「변수와 부작용」을 참고하세요.
